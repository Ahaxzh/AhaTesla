- **项目方向判定**: **没有偏差**。PRD v1.3 的定位（TeslaMate 生态的生活化账本 + 多渠道推送、只读红线、不做控制/不做云）与竞品调研结论高度一致 —— 该生态确实存在"Grafana 极客面板 ↔ 生活记账"的空白，且 FIFO 批次账本是全场唯一（Tessie/evcc 只记录成本、不与真实充电账单对账闭合）。护城河判断成立。
- **最重要的一句话**: 修掉了「FIFO 账本从不回放历史消耗」这一根基性 bug —— 此前每页行程都对着从未被扣减的满额批次池从最老批次抽电，行程电费系统性错配；现在全站共用一次全量回放，任意页面每公里成本一致，账本闭合（Σ分摊 ≡ 实付）真正成立。

### 严重（钱算错 / 功能静默失效）

| # | Bug | 根因 | 修复 |

| S2 | **TOU 分时电价整夜谷电按峰价计**：窗口按北京墙钟配置，代码用 `getUTCHours()` 归类分钟 → 差 8 小时，谷段全判峰段（金额差 ~4 倍） | 时区语义错位（测试注释自己写着"UTC"） | `touSplitSession` 按实例时区墙钟归类（偏移按天缓存）；契约 §8.1 补口径；新增北京整夜谷电回归测试 |

## 三、安全加固（审计 + 修复）

红线核验：**四条红线在代码层全部成立**（只读 SELECT、无控制命令、密文落盘、无多用户）；MQTT 只订阅。修复的 12 项纵深缺陷：

1. **默认只绑 127.0.0.1**（原 `0.0.0.0` 硬编码；compose 显式 `HOST=0.0.0.0` 保持容器映射）
2. **Cookie 自动 Secure**（HTTPS 反代/TLsocket 下；localhost 开发不受影响）
3. **MQTT_URL 凭据脱敏**再进日志（红线 2 漏洞）
4. **access token 带 ep**：revoke-all/改密后旧 access 立即失效（原来还能用满 24h）；refresh token 不得当 access 用
5. **登录限速按 IP 分桶**（原全局单桶 = 任何人 5 次错试就能把主人锁门外）
6. /setup 注册竞态占位（并发后写者胜）
7. 5xx 不再回传原始 error.message（pg/SQL 片段防泄露）
8. 畸形 Cookie 百分号编码不再炸连接
9. 运行池每连接 `SET default_transaction_read_only=on`（原只有 setup 探测池有 —— 契约 §1 终于名副其实）
10. **全栈 compose 只读账号独立密码** `TM_RO_PASSWORD`（原与 teslamate 超级用户同密）
11. **Service Worker 不再缓存 /api/**（GPS 轨迹/账单曾永久留在 Cache Storage，登出不清除；失败响应也会被回放）
12. compose/README 删掉"改成 4000:4000"的危险指引，改为 SSH 隧道说明（TeslaMate :4000 无密码且可下发车辆指令）

遗留（未修，列入路线图）：AC-4.1 的"管理员鉴权反代 TeslaMate Web"未实现（LiveView 需 WS 代理，半吊子实现比不做更危险，见 §6）；/api/ledger/recalculate 的 from/to 语义仍按全量重算（行为收敛后无正确性影响）；datasource 向导保存后运行时仍用 DB_URL（connect 模式主路径不受影响）。

## 六、方向验证与竞品结论（调研子代理，一手来源）

**定位成立**：TeslaMate 是记录器+Grafana（无 API、无导出，社区 #451 多年要不到 CSV）；tesla-butler 证明价值但是 Mac 单机单人无测试；Tessie 闭源收费不做真实账单对账；evcc 是充电桩侧不碰行车账本。"**复用 TeslaMate 数据的中文友好记账+推送**"无人占据，且 FIFO 批次账本（充的钱按批次摊到后续行程、与实付闭合）是全场唯一实现 —— 这是护城河，不是功能清单的一项。

**做得好的（保持）**：推送事件体系（9 事件×6 渠道矩阵+静音时段+早报合并）已超过 tesla-butler；GCJ02 纠偏/高德底图/围栏计价是正确的本地化选择；工程纪律（测试/契约/e2e）显著优于同类。

**路线图建议（按 价值÷成本 排序，详见调研报告）**：
1. **CSV 导出**（trips/charges/bills；TeslaMate 社区第一呼声，Tessie/evcc 标配，成本最低的可信度提升）
2. **电池健康卡**（满电续航平滑趋势 → 健康度%；Tessie 产品化验证过，TeslaMate 社区反复要求可配置新容量）
3. **通知模板编辑器**（evcc 式 `${变量}` 每渠道可编辑+预览；把 9×6 矩阵的内容层交给用户）
4. **维护提醒**（轮胎换位按里程/空调滤芯按时间 —— 纯 odometer 算术，Tessie 六件套的低配版）
5. **真实续航**（近 30 天实际能耗 → "≈312km" 展示；Tessie 独有，配合高德可做"还能到哪"）
6. AC-4.1 鉴权反代（用 WS 感知的方案做，或文档化为 SSH 隧道标准路径）
7. **不要做**：车辆控制（红线）、光伏/桩管理（evcc 域）、找桩/支付、云端排行榜、仪表盘构建器（重造 Grafana）
